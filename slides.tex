\headline{Motivation}
\hypertarget{sec:motivation}{}
\vfill
\begin{itemize}
  \item Most neural machine translation (NMT) systems translate sentence by sentence
  \item[]
  \item Make use of other sentences in addition to exploit context information
  \begin{itemize}
    \item reduce ambiguities in translation choices
    \item example: cross-sentence anaphora \cite{voita_2018}
  \end{itemize}
\end{itemize}
\vspace*{0.5cm}

 	\caption{An English$
 		\to$German example of a cross-sentence anaphora problem. The translation of the pronoun '\textcolor{orange}{it}' depends on the previous sentence.}

\headline{State of the Art Literature}
\hypertarget{sec:sota}{}
\vfill
\begin{itemize}
  	\item Single encoder: concatenate sentences on source-/target side \\ \cite{tiedemann_2017,agrawal_2018}
  	\vspace*{1cm}
  	\item Multi-Encoder with attention mechanism
  	\begin{itemize}
  		\item Local context: feed surrounding sentences into seperate encoders. Combine context vectors:
  		\begin{itemize}
  			\item concatenation (like in \cite{zoph_2016})
  			\item gated sum \cite{bawden_2018}
  			\item hierarchical attention \cite{bawden_2018}
  		\end{itemize}
  	\end{itemize}
\end{itemize}
\vspace*{0.5cm}
Remark: above methods only consider \emph{local} context
