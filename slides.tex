\headline{Motivation}
\hypertarget{sec:motivation}{}
\vfill
\begin{itemize}
  \item Most neural machine translation (NMT) systems translate sentence by sentence
  \item[]
  \item Make use of surrounding sentences to exploit context information
  \begin{itemize}
    \item reduce ambiguities in translation choices
    \item example: cross-sentence anaphora in English$\to$German
  \end{itemize}
\end{itemize}

\headline{State of the Art Literature}
\hypertarget{sec:sota}{}
\vfill
\begin{itemize}
  	\item Single encoder: concatenate sentences on source-/target side \\ \cite{tiedemann_2017,agrawal_2018}
  	\vspace*{1cm}
  	\item Multi-Encoder with attention mechanism
  	\begin{itemize}
  		\item Feed surrounding sentences into seperate encoders and combine context vectors:
  		\begin{itemize}
  			\item concatenation (like in \cite{zoph_2016})
  			\item gated sum \cite{bawden_2018}
  			\item hierarchical attention \cite{bawden_2018}
  		\end{itemize}
  	\end{itemize}
\end{itemize}
\vspace*{2cm}
Remark: above methods only consider \emph{local} context
\vfill

\headline{Ongoing Work at i6}
\hypertarget{sec:ongoing_work}{}
\vfill
\begin{enumerate}
	\item Reproduce results from \cite{agrawal_2018}
	\begin{itemize}
		\item Transformer model
    \item IWSLT 2017 English$\to$Italian
		\item concatenate sentences with special token $<$BREAK$>$, \\
    example: \texttt{sentence\_1} $<$BREAK$>$ \texttt{sentence\_2}
 	\end{itemize}
    \item Compress context-sentences by pruning
    \begin{itemize}
      \item first $n$ most-common words in training corpus
      \item pre-defined stopword list
    \end{itemize}
  \item Test method of concatenation ($+$ pruning) on WMT 2018 German$\to$English data as well
\end{enumerate}

\headline{Summary and Future Work}
\vfill
\begin{itemize}
  \item Concatenation of sentences yield slight performance increases with regards to BLEU and TER metrics
  \begin{itemize}
    \item preliminary results on WMT 2018 German$\to$English
  \end{itemize}
  \item Simple compression by pruning words according to frequencies
  \begin{itemize}
    \item IWSLT data set: up to $+$1 BLEU improvement
    \item WMT data set: \ToDo{check values}
  \end{itemize}
\end{itemize}
\vspace*{1cm}
Future work:
\begin{itemize}
  \item Implementation of multi-encoder approaches\\ \cite{bawden_2018,voita_2018}
  \item Test approaches in discourse-heavy data sets \\ like OpenSubtitles \cite{lison_2016}
  \item Consider global context information: e.g. topic embedding
\end{itemize}
